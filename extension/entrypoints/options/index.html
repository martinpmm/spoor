Bridge

The bridge mirrors your events into ~/.spoor/events.db so Claude can read them through the local MCP server. Until it is installed, everything stays in the browser and is sent later; nothing is lost.

  1. In a terminal, at the root of the Spoor repository: npm install && npm run build
  2. Then: npm run register
  3. Click “Reconnect”.
