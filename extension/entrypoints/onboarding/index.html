Spoor REC
Welcome · Local only

Spoor is now recording this browser

Spoor records how work happens in this browser so you can ask your own Claude which workflows repeat and which ones are worth automating. Everything stays on this computer.

Use rule. Spoor records everything a person does in the browser, including what they type. Install it only on your own browser, or with the informed consent of the person who uses that browser.
01 · Recorded

What is recorded

  • Sites and screens you visit, with time spent (addresses are turned into templates such as /invoices/{id}/edit; query strings are dropped).
  • Clicks, form submits, file uploads (file names only), copy and paste (first 200 characters).
  • The final value you type into each field (up to 1000 characters), once per field, not each keystroke.
  • Prompts you send to ChatGPT, Claude, Gemini and Copilot, with their text.
  • Focus, idle and active periods, grouped into sessions (a new one after 5 minutes idle).
02 · Never recorded

What is never recorded

  • Password fields, and fields marked as current or new password, card data or one time code.
  • Hidden inputs, and fields whose name or label says password, passcode, PIN, CVV, secret, token, contraseña, clave…
  • Anything in incognito windows.
  • Screenshots or page content.

Careful: a password typed into a normal field (for example a user name box) or pasted from a password manager into one is recorded like any other text. Use pause or the exclude list on sensitive sites.

03 · Storage

Where the data lives

  • In this browser (IndexedDB), for the dashboard.
  • If you install the bridge: in ~/.spoor/events.db, readable only by your user account.
  • Spoor makes no network requests. There is no server, no account and no telemetry.
  • When you ask Claude about your data, the results of the tools it calls become part of that conversation. Turn off “Let Claude read typed values” in settings to share only lengths.
  • Events older than 30 days are deleted automatically (configurable). One button deletes everything.
04 · Controls

Your controls

  • The toolbar badge always shows REC or OFF.
  • The toolbar button pauses for 15 minutes, 1 hour or until you resume, and excludes the current site.
  • Settings: all sites, all sites except a list, or only listed sites; value capture; retention.

05 · Optional

Connect Claude

  1. At the root of the Spoor repository: npm install && npm run build, then npm run register.
  2. Add the spoor MCP server to Claude Desktop or Claude Code (the register script prints the exact block).
  3. Ask: “What are my five most repeated workflows this week and how long does each take?”
